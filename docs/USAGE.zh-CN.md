# 中文使用说明

[返回中文首页](../README.zh-CN.md)

## 1. 添加与管理文件

支持 `.pdf`、`.doc`、`.docx`、`.xls`、`.xlsx`、`.xlsm`、`.ppt`、`.pptx`。可拖入文件，或通过“添加文件”“添加文件夹”加入队列。添加文件夹时会递归查找子文件夹；相同路径的文件不会重复加入。

### 勾选与选中有什么区别？

| 操作 | 打印范围 |
| --- | --- |
| 开始打印 | 列表中所有已勾选的文件 |
| 打印所选文件 | 当前选中行对应的文件，包括未勾选的行 |
| 重试失败任务 | 已勾选且状态为“失败”的文件 |

点击文件行可以追加或取消选中，空格键切换选中行的勾选状态。可拖动行或使用 `Alt+↑/↓` 调整顺序。

点击“移出列表”或按 `Delete` 只移除任务，**不会删除磁盘上的原文件**。

## 2. 打印设置

- **打印机**：使用 Windows 默认打印机，或指定打印机；也可为选中的文件单独指定。
- **份数**：设置打印份数。
- **双面打印**：单面打印、长边翻页、短边翻页。实际效果取决于设备和驱动支持。
- **纸张尺寸**：默认使用打印机设置，也可从打印机提供的尺寸中选择。应用会检查部分文档的纸张尺寸，不匹配时可能阻止打印并给出提示。

文件类型规则用于按扩展名选择打印机，例如 `.pdf` 使用打印机 A、`.xlsx` 使用打印机 B。“应用规则（保留手动设置）”保留手动指定的打印机；“应用规则（全部覆盖）”重新为全部任务指定打印机。

## 3. PDF

支持自动缩放、适配页面、仅缩小、原始尺寸等模式，可设置缩放比例、自动旋转和居中。选中文件后，可通过“PDF 选项”设置这些 PDF 的单独选项。

“打印边距测试”会实际发送测试页。“显示裁切警告”用于提示部分原始尺寸打印可能超出可打印区域的情况。首次使用某台打印机时，建议先打印少量页面确认效果。

## 4. Excel 工作表与方向

选中一个 Excel 文件后，可打开“Excel 工作表”选择打印范围；默认打印全部工作表。

| 打印方向 | 行为 |
| --- | --- |
| 自动调整 | 根据工作表已用区域的宽高，为每张工作表判断横向或纵向 |
| 打印前确认 | 先显示文件级建议，再由用户勾选是否自动调整 |
| 不更改 | 保留工作表原有方向 |

方向建议是基于已用区域宽高的启发式判断，不保证所有复杂排版都合适。确认窗口汇总文件内工作表的建议；勾选后，打印时仍会分别判断每张工作表的方向。

## 5. 语言与主题

在右侧“显示”区域切换语言和主题。中文界面优先使用系统已安装的微软雅黑；没有匹配字体时回退到系统字体。跟随系统模式会将中文 Windows 映射为简体中文，目前没有独立的繁体中文翻译。

## 6. 错误与配置位置

通过“帮助 → 日志摘要”查看失败文件、摘要和原始详情，或点击“打开日志”。应用自身的错误提示支持中文，第三方组件和驱动返回的信息可能为其他语言。

| 运行方式 | 设置与规则 | 日志 |
| --- | --- | --- |
| 从源码运行 | 项目中的 `app\config\user_settings.json`、`app\config\rules.json` | `app\logging\app.log` |
| 打包后的程序 | `%LOCALAPPDATA%\RakuPrint\config\` | `%LOCALAPPDATA%\RakuPrint\logging\app.log` |

## 8. 指定打印页

1. 在列表中选中一个或多个文件。
2. 点击工具栏或右键菜单中的“指定打印页”，也可按 `Ctrl+Alt+R`，或双击“打印页码”列。
3. 为每个文件填写独立的页码范围，点击“确定”。
4. 点击“打印所选文件”；如果点击“开始打印”，则仍然打印所有已勾选文件，每个文件使用各自的页码设置。

| 输入示例 | 打印范围 |
| --- | --- |
| 留空 | 全部页 |
| `2` | 仅第 2 页 |
| `3-6` | 第 3 至第 6 页 |
| `1,3,5-8` | 第 1、3、5、6、7、8 页 |

页码从 **1** 开始，表示最终打印内容中的物理页面顺序，不是页眉页脚中的页码标签。重复页码会去重，并按升序打印；也接受中文逗号、顿号和全角数字。

- **PDF**：按原 PDF 页面顺序计数。
- **Word**：按完成排版后的页面顺序计数，分节后的页码重置不影响此编号。
- **PowerPoint**：一张幻灯片对应一页，页码与幻灯片顺序一致；指定页打印包含所指定的隐藏幻灯片。
- **Excel**：先应用打印方向、纸张和工作表设置，再按打印页面的连续顺序计数。选择部分工作表时，按照已选工作表的顺序合并计数。例如，第一张工作表打印 2 页、第二张工作表打印 3 页，则 `3` 表示第二张工作表的第一个打印页；不是每张表都打印第 3 页。

已知页数时，设置窗口会拦截越界输入。Excel 页数会随排版变化，因此会在打印前根据最终结果校验。非法或越界页码会导致该文件报错，不会退回打印全部页；同队列其他文件仍按各自设置执行。

Office 指定页打印使用应用自身导出的临时 PDF，再取所需页面。原文件不被改写，临时文件会在任务结束后清理。原有预览仍显示原文档内容；实际打印范围以列表的“打印页码”列为准。页码设置属于当前队列任务，移除任务或重新启动后不会保存。
